# docs/history

Documents kept for the record, **not** descriptions of the current code. Each
starts with a note saying what it was and what is different now.

| file | what it was |
|---|---|
| `stormblock-spec.md` | the original v0.1 design spec (2026-02), before slabs and the GEM |
| `linuxboot-iscsi-spec.md` | a coreboot/LinuxBoot boot proposal (2026-03), not pursued |
| `data-placement.md` | a placement design note (2026-08-28), superseded by per-volume redundancy |
| `presentation-2026-08.html` | the v7.1.0 deck (2026-08-10) |

`docs/stormblock-ipxe-boot.md` (a 2026-03 lab runbook) was removed rather than
archived: it documented a `serve-boot` subcommand that never existed and a
re-boot path that formats the disk (#131).
